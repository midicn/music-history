# midicn · 音乐史

这是 [音乐史](https://hist.midicn.com/) 的双语内容真源；网站产物位于 [midicn/hist](https://github.com/midicn/hist)。

沿时间与地域阅读人类音乐史，串起全球音乐传统、流派、人物、作品与文化交流。

每条内容使用 Markdown 与 YAML 元数据，同一文件内以 `::: zh` 和 `::: en` 编写中英两版。
`instances` 指向曲库中的真实曲目，`[[类型:ID]]` 由实体注册表解析为站内或跨站链接。

- `_home.json`：首页导航配置。

首页配置属于构建输入，与正文一起维护。作者笔记和进度文件不属于公开内容。
